[module] ensemble_learning

Ансамбль

Комбинирование нескольких моделей в один сильный предиктор.

← Главная

Кратко

Ансамбли снижают variance и/или bias за счёт объединения разных моделей.

Именования (RU / EN)

  • Ансамблевое обучение
  • Комитет моделей
  • Ensemble learning
  • Model aggregation

Сценарии

  • Gradient Boosting для табличных данных
  • Random Forest в классификации
  • Stacking в соревновательном ML

Плюсы / Минусы

  • Плюсы: рост качества и стабильности.
  • Минусы: тяжелее интерпретировать и обслуживать.

Пошагово

  1. Подобрать разнообразные базовые модели
  2. Обучить их независимо/последовательно
  3. Объединить (vote/average/stack)
  4. Оценить прирост по метрикам и latency
