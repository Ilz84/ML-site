[module] unsupervised_learning

Обучение без учителя

Поиск структуры в данных без целевых меток.

← Главная

Кратко

Модель сама выявляет закономерности: кластеры, факторы, аномалии, представления.

Именования (RU / EN)

  • Обучение без учителя
  • Неразмеченное обучение
  • Unsupervised learning
  • Learning from unlabeled data

Популярные сценарии

  • Сегментация клиентов
  • Поиск аномалий в логах и транзакциях
  • Снижение размерности (PCA/UMAP)
  • Тематическое моделирование текстов

Плюсы / Минусы

  • Плюсы: не нужны метки, открывает скрытые паттерны.
  • Минусы: сложнее валидация, неоднозначная интерпретация.

Пошагово

  1. Сбор сырых данных
  2. Предобработка и нормализация
  3. Выбор метода (кластеризация/DR/аномалии)
  4. Подбор гиперпараметров
  5. Интерпретация и бизнес-проверка
