[module] semi_supervised_learning

Обучение с частичным самообучением (Semi-supervised)

Мало размеченных данных + много неразмеченных.

← Главная

Кратко

Комбинирует supervised и unsupervised подходы для повышения качества при нехватке меток.

Именования (RU / EN)

  • Полу-контролируемое обучение
  • Частично контролируемое обучение
  • Semi-supervised learning
  • Learning with few labels

Сценарии

  • Классификация изображений при дефиците разметки
  • NLP-задачи в узкой предметной области
  • Био/мед-данные, где разметка дорогая

Плюсы / Минусы

  • Плюсы: лучше, чем только на малом labeled-наборе.
  • Минусы: риск накопления ошибок в псевдометках.

Пошагово

  1. Обучить базовую модель на labeled-части
  2. Сгенерировать псевдометки для unlabeled
  3. Отфильтровать по confidence
  4. Дообучить на объединённом наборе
  5. Итеративно повторять цикл
